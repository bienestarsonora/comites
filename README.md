# Plataforma de Comités de Contraloría y Participación Social

Prototipo funcional desarrollado con HTML5, CSS3 y JavaScript Vanilla, compatible con GitHub Pages.

## Ajustes de esta versión

- Integra Comités de Contraloría Social y Comités de Participación Social.
- Controles de Leaflet personalizados con la identidad institucional.
- Popup del mapa rediseñado.
- Corrección de capas y `z-index`: el mapa ya no se superpone a la ficha del comité.
- El popup del mapa se cierra antes de abrir la ficha completa.

## Ejecución

Abra `index.html` en un navegador con conexión a internet para cargar Leaflet, OpenStreetMap, Chart.js y las tipografías externas.
